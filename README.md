# Project: Linked Lists

## About the Project

This is a linked list project as part of "The Odin Project". Practicing my skills with data structures, I had to create a singly linked list from scratch using JavaScript. The project involved creating nodes and implementing methods to add, remove, find, and access nodes within the list.

## Skills Practiced

- Data Structures
- Working with Objects and References
- Linked List Traversal
- Node Insertion and Removal
- Handling Edge Cases and Errors
- Testing with Jest
- Debugging and Refactoring
